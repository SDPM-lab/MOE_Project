# 生成式 AI 協作軟體工程人才培育計畫（B 類）申請書

教育部「創新典範資訊軟體人才培育計畫」AI 跨域實踐人才培育示範系所（B 類）申請書內文草稿。
申請單位：國立高雄師範大學 軟體工程與管理學系。

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `生成式AI協作軟體工程人才培育計畫_B類申請書_貳至肆.docx` | 申請書第貳至肆章（全程計畫摘要、116 年度計畫執行規劃、116 年度重點工作查核點），A4 共 20 頁（上限 25 頁） |
| `src/build_docx.js` | 產生 Word 檔之腳本（內文皆在此檔） |
| `src/figs/` | 圖 1–4：圖 1 為計畫架構圖原圖；圖 2–4 由 HTML/SVG 繪製後轉為 PNG |

## 待補資料

文件中以**黃色螢光**標示須由計畫團隊依實際情形填寫或確認之處：

- 主持人、協同主持人、授課教師、跨域教師與業師姓名（表 4、表 6、表 18）
- 團隊成員近五年軟體開發課程教學實績（表 4）
- 既有課程前一次開課之學期與修課人數（表 7）
- 系課程委員會審議日期（參、二、2）
- 合作場域與企業名稱（表 13）
- 其他補助計畫彙整表（表 16）
- 經費額度：表 3 為規劃值，請依教育部核定補助上限調整

## 重新產生

```bash
# 需安裝 docx（npm）；圖 2–4 另需 playwright（Chromium）
node src/figs/render.js src/figs/fig2_org.html src/figs/fig3_map.html src/figs/fig4_fde.html
node src/build_docx.js
```
