## 公開版與完整版

本儲存庫為公開專案，因此不收錄個人與帳戶資料：計畫主持人與聯絡人之電話、電子郵件與傳真，受領人金融機構、戶名、帳號與統一編號，以及主要參與人員簡歷，皆存放於 `src/private_data.json`，並已列入 `.gitignore`。

- 本機有 `src/private_data.json` 時，`node src/build_docx.js` 產生完整版 `生成式AI協作軟體工程人才培育計畫_B類申請書.docx`；此檔同樣不納入版本控制。
- 沒有該檔時，或加上 `--public` 參數時，則產生公開版 `…_公開版.docx`。

兩版排版與頁碼完全相同，提交教育部時請使用完整版。

## 重新產生

```bash
# 需安裝 docx（npm）；圖 2–5 另需 playwright（Chromium）
node src/figs/render.js src/figs/fig2_org.html src/figs/fig3_map.html src/figs/fig4_fde.html src/figs/fig5_microsystem.html
node src/build_docx.js            # 有 src/private_data.json 時產生完整版，否則產生公開版（加 --public 可強制產生公開版）
soffice --headless --convert-to pdf <產生的 docx>
python3 src/update_toc_pages.py <轉出的 pdf>   # 更新目次頁碼
node src/build_docx.js            # 以正確頁碼重新產生
```

在 Word 中也可於目次上按右鍵「更新功能變數」重新計算頁碼。`src/build_docx.js` 中的 `LINE_SCALE` 可微調整體行距；目前設定在行高 ±2% 的排版差異下，貳至肆章仍維持 25 頁。
